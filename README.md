# Tugas 1 Pemrograman PHP

1. Implementasikan materi struktur kendali dan form processing.
2. Buatlah sebuah form dengan input: Nama, Email, Nilai Ujian
3. Buatlah struktur kendali:
   - Jika nilai ujian > 70, maka Lulus.
   - Jika nilai ujian < 70 maka Remedial.
4. Tampilkan outputnya ke dalam halaman browser.
